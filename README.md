#### About

This repository is for the Ghost Delivery Admin Panel.

#### Recommended Versions

- Node.js: v16.20.2
- npm: 7.24.2

#### Running Instructions

To run the Ghost Delivery Admin Panel, follow these steps:

1. Install dependencies:

   ```sh
   npm install
   ```

2. Start the development server:

   ```sh
   npm run dev
   ```
